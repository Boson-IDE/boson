# Boson Documentation

Welcome. This is the documentation that ships with Boson, and you are reading it inside Boson. Open it any time from **Help → Documentation**, or press `Ctrl/Cmd+Shift+P` (or `F1`) and run **Documentation**.

## Find your way

The list on the left shows every document. Type in the search box to filter by file name. Documents are grouped in folders:

| Folder | For | Contents |
|---|---|---|
| `guide/` | Using Boson | Getting started, workspaces, projects, language support, themes, plugins, troubleshooting, this viewer |
| `reference/` | Looking things up | The Workspace Runtime (configuration and API), security |
| `development/` | Changing Boson | Architecture, building and packaging, contributing |
| `web/` | Interactive pages | The keyboard-shortcut finder and an example web document |

## Start here
