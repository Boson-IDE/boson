# Contributing

The contributing guide lives with the rest of the documentation so it can be read inside Boson (**Help → Documentation**):

**[docs/development/contributing.md](docs/development/contributing.md)**

It covers where code belongs, the checks to run before a change (`npm run typecheck`, `npm run build`, `npm test`), the workflows for adding Runtime files, language servers, templates and routes, how to write documentation, and the UI and localization rules. For the product direction and roadmap, see [AGENTS.md](AGENTS.md).
